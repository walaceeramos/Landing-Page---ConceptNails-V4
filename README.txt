# ConceptNails Landing Page

Arquivos:
- index.html
- style.css
- script.js
- assets/

## Como abrir
1. Extraia a pasta.
2. Abra a pasta `conceptnails-lp` no VS Code.
3. Clique duas vezes em `index.html` ou use uma extensão como Live Server.

## Onde editar
- Textos e seções: `index.html`
- Cores, fontes e layout: `style.css`
- Formulário e interações: `script.js`
